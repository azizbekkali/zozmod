Frequently Asked Questions

Get answers to common questions about ZoZ Mod

All mods on ZoZ Mod are thoroughly tested for viruses and malware before being made available for download. However, we always recommend using mods responsibly and at your own discretion.

While we take measures to make our mods as undetectable as possible, there is always some risk when modifying games. We recommend using alternate accounts when possible and not overusing obvious mod features in multiplayer games.

We update our mods as soon as possible after game updates. Popular mods are usually updated within 24-48 hours of a new game version release. You can check the "Last Updated" date on each mod's page.

Most of our mods work without root or jailbreak. If a mod requires special permissions, it will be clearly stated in the mod description along with installation instructions.
